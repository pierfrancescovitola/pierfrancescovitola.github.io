# Project guidance

## Publishing and privacy
- Never publish, commit, or transmit credentials, authentication tokens, private keys, or other secrets.
- Treat personal contact details and information in the CV as private source material; include it in the local site only for this requested portfolio.
- Never push changes to GitHub, deploy the site, or make the site public unless Pierfrancesco explicitly asks.
- Do not add information that is not present in the CV or explicitly supplied by Pierfrancesco.

## Ask first
- Ask before publishing or sharing any project content outside this local workspace.
- Ask before omitting, rewriting materially, or adding personal or professional details beyond the requested presentation.
- Ask when a requested change could expose sensitive personal information beyond the CV content intended for this site.

- Preserve the CV's section order and all of its information.
- Prefer clear, accessible, responsive HTML and CSS with concise, direct language.
- Keep changes focused on the requested personal website and its documentation.
